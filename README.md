# Project: Landing Page

A responsive landing page built with semantic HTML5 and CSS Flexbox as part of **The Odin Project** Foundations curriculum.

## Live Demo
* [View Live Site](https://zackmadness.github.io/Project-Landing-Page/) 

## Features
* **Semantic HTML5:** Structured using `<header>`, `<nav>`, `<main>`, `<section>`, `<figure>`, `<blockquote>`, and `<footer>`.
* **CSS Flexbox Layout:** Built using Flexbox alignment (`justify-content`, `align-items`, `flex-wrap`, and `gap`) without external frameworks.
* **Custom Styling:** Matches The Odin Project design specification with custom typography, color palette, and rounded image cards.
